Third-party components in Lantern Engine
========================================

This file lists the third-party software shipped in this package: what it is, its exact version,
its license and where its license text is in the package. Paths are relative to the package
folder. Lantern Engine's own code and its terms are described in NOTICE and LICENSE.


1. MSYS2 CLANG64 libraries (engine/out/*.dll)
---------------------------------------------

These DLLs are unchanged binaries from MSYS2 CLANG64 packages (https://www.msys2.org/). Each entry
names the package and version as installed when the package was built (pacman -Q), the license
the MSYS2 package declares, the folder of its license texts, the DLLs it provides, and the MSYS2
source package for that exact version.

FFmpeg (avcodec, avformat, avutil, swresample, swscale) is built by MSYS2 with --enable-gpl and
--enable-version3, with libx264, libx265, libxvid and opencore-amr, and is therefore distributed
under the GNU General Public License version 3 or later (engine/licenses/msys2/ffmpeg/COPYING.GPLv3).

Source code. The GPL- and LGPL-licensed libraries in this section are cairo
1.18.6-2, ffmpeg 9.0.2-1, freetype 2.14.3-1, fribidi 1.0.17-1, gdk-pixbuf2 2.44.8-1,
gettext-runtime 1.0-1, glib2 2.90.1-1, gmp 6.3.0-2, gnutls 3.8.13-3, graphite2 1.3.15-1,
jbigkit 2.1-6, lame 3.100-3, lcms2 2.19.1-1, libbluray 1.5.0-1, libdatrie 0.2.14-1, libgme 0.6.5-2,
libiconv 1.19-1, libidn2 2.3.8-4, librsvg 2.63.2-1, libsoxr 0.1.3-6, libssh 0.12.2-1,
libtasn1 4.21.0-1, libthai 0.1.30-1, libunistring 1.4.2-1, libx264 0.165.r3222.b35605a-3,
nettle 4.0-1, pango 1.58.2-1, rtmpdump 2.6-2, x265 4.3-1, xvidcore 1.3.7-5, xxhash 0.8.4-1,
